## Features

- PDF Document Processing: Automatic extraction, text normalization, and chunking of PDF documents
- Vector Embeddings: Uses OpenAI embeddings for semantic understanding of text
- Vector Database: Qdrant for high-performance vector similarity search
- Semantic Search: Natural language queries to find relevant document sections
- Document Management: List and filter uploaded documents
- Database Flexibility: Support for both PostgreSQL (production) and PGLite (development/testing)
- Hexagonal Architecture: Clean separation of business logic from external dependencies
